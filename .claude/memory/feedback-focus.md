用户明确表达过不满："你的思维混乱了"——当我在多个问题间来回跳、反复自我怀疑、或在"调查-分类-修复"里打转时。

**Why:** 冗余的思维输出浪费注意力，用户在等待明确的结果而不是过程叙事。

**How to apply:** 每个回复聚焦一个决策点或成果。遇到多个方向时：简明陈述现状 → 列出选项 → 让用户定方向。修复循环中若发现某类错误可能是工具误报，先抽查定性再批量修，不要盲目修下去。
